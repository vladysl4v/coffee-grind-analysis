# Coffee Grind Fineness Dataset


## Setup

This project uses [uv](https://github.com/astral-sh/uv) for dependency management.

```bash
# install uv (once)
curl -LsSf https://astral.sh/uv/install.sh | sh

# create venv and install dependencies
uv sync
```

### Adding your images

Place your real coffee grind images in:

```
data/images/raw/
```

### Synthetic data (optional, for training)

Synthetic images are generated by Blender and then compiled into the training dataset in two steps.

**1. Generate images** (requires Blender 4.0+):

```bash
blender --background --python synth/generate.py
```

Output lands in `synth/images/` — one `.png` and one `.json` per sample.

**2. Compile into training data:**

```bash
python synth/compile_dataset.py          # all images
python synth/compile_dataset.py --max 1500  # cap at 1500 (best known config)
```

This copies the images to `data/images/synthetic/` and writes `data/labels/synthetic.csv`. The train script picks these up automatically.

## Project layout

```
    synthetic/    ← synthetic images (gitignored)

    test.csv

  runs/           ← training outputs (gitignored)
```

## Data

### Split

4 consecutive photos of the same grain share the same fineness value. The split operates on **grain groups** to prevent leakage.

| Split | Groups | Images |
|-------|--------|--------|
| Train | 115 (79%) | 489 |
| Val   | 15 (10%)  | 60  |
| Test  | 16 (11%)  | 58  |

607 images pass quality filtering (41 blurry images removed). Fixed seed `SEED = 42`.

> **Do not regenerate the split CSVs** — doing so reshuffles the data and invalidates comparisons with existing runs.

If you ever need to regenerate the split (e.g. after adding new images), run:

```bash
uv run utils/split_labels.py --source raw
```

This runs quality filtering automatically and writes `train.csv`, `val.csv`, `test.csv` to `data/labels/`. Requires `data/labels/labels_train2.csv` (semicolon-delimited, `Sample;Fineness`).

## State-of-the-art model

**ConvNeXt-Small · 420 px crop · 1 500 synthetic images — Val MAE 2.31%**

Best model checkpoint: `data/runs/convnext_small/run_069/best_model.pt`

### Architecture & config

| Setting | Value |
|---------|-------|
| Backbone | ConvNeXt-Small (ImageNet-1k pretrained) |
| Head | single `Linear(768 → 1)` replacing the classifier |
| Loss | MSELoss |
| Optimiser | Adam |
| Learning rate | 1e-3 (head) → 1e-4 (backbone after unfreeze) |
| LR schedule | ReduceLROnPlateau · factor 0.5 · patience 5 |
| Batch size | 32 |
| Max epochs | 100 |
| Early stopping | patience 12 (on val MAE) |
| Unfreeze backbone | after epoch 15 |
| Synthetic images | 1 500 (capped, mixed into every train batch) |
| Synthetic val fraction | 10 % of synth added to val for monitoring |

### Preprocessing

Images are loaded in full resolution and a **420 px centre crop** is taken — no resize. This preserves particle-level texture that a resize-to-224 would destroy.

```
CenterCrop(420) → ToTensor() → Normalize(mean=[0.1557, 0.0899, 0.0404],
                                          std= [0.0483, 0.0349, 0.0190])
```

No augmentations — the best result was achieved without them.

### Train

```bash
uv run src/train.py
```

Config is hardcoded in `train.py` — no CLI arguments needed. Saves `best_model.pt` to `data/runs/run_NNN/`.

### Run inference on new images

```bash
# single image
uv run src/inference.py <model.pt> <image.jpg>

# folder of images
uv run src/inference.py <model.pt> <folder/>
```

Example with the best model:

```bash
uv run src/inference.py data/runs/convnext_small/run_069/best_model.pt data/images/raw/IMG_5749.png
```

Run from the project root. Avoid absolute paths with backslashes — they break in Bash.

## Evaluation & utils

### Evaluate on val and test

```bash
uv run utils/evaluate.py data/runs/convnext_small/run_069/best_model.pt
```

Prints MAE, RMSE, bias, std, p80, p95 for both splits. Saves to the run directory:
- `eval_predictions_val.csv` / `eval_predictions_test.csv`
- `eval_scatter_val.png` / `eval_scatter_test.png`
- `eval_error_val.png` / `eval_error_test.png`

### Conformal prediction

```bash
uv run utils/plot_conformal.py data/runs/convnext_small/run_069/best_model.pt
uv run utils/plot_conformal.py data/runs/convnext_small/run_069/best_model.pt --alpha 0.05
```
